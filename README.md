# Kairos Interactive One-Pager

GitHub Pages-ready interactive HTML company profile.

## Publish
1. Upload **index.html** and the **kairos_assets** folder to the root of your GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save and wait for GitHub Pages to deploy.

Do not put `index.html` inside another folder.
